# Family Secret Santa

A single static page for drawing Secret Santa names, hosted on GitHub Pages.

1. Open the page, add everyone, tick who's a kid and pick which parent gets each kid's link.
2. Press **Draw names**. You get one message per parent with their own link and their kids' links, ready to share by text, email or any chat app.
3. Each link opens a present to tap, which reveals who that person is buying for.

The organiser never sees who drew who. The draw is stored in each link, so there's no server or database.

To host it: **Settings → Pages → Deploy from a branch → main / (root)**.
